One-Time Setup
Connect to GitHub so every change you make saves instantly to your live site — no file downloads, ever.
1
Go to github.com → sign in → click your profile photo (top right) → Settings → scroll to the bottom → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
2
Give it a name like eliteautohaus-admin. Under Select scopes, check the box next to repo (first one in the list). Scroll down → click Generate token. Copy the token — it starts with ghp_
3
Fill in the fields below. Your GitHub username and the name of your repository (the one where your site files live).
⚠️ Just the short name — NOT the full URL.
Example: if your site is eliteautohaus.github.io/lnc → type lnc
If it's eliteautohaus.github.io → type eliteautohaus.github.io
